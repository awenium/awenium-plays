# Awenium Plays

A neon gaming website with seven browser mini-games:
- Snake
- Tic Tac Toe
- Chess practice board
- Speed Runner
- Cycle Rush
- Neon Archery
- Mind Matrix

## Put it online free with GitHub Pages
1. Create a GitHub account at https://github.com
2. Create a new **public** repository named `awenium-plays`.
3. Upload `index.html`, `style.css`, and `games.js`.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
6. GitHub will give you a free Pages address such as `https://YOUR-USERNAME.github.io/awenium-plays/`.
7. To make it easier to find on Google, submit the Pages URL to Google Search Console after it is live. Google indexing is not guaranteed or instant.

Creator credit and phone number are included in the site as requested.
